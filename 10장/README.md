# 10장 - 템플릿과 STL

템플릿 함수·템플릿 클래스로 자료형에 독립적인 코드를 작성하는 법을 배우고, STL의 컨테이너·이터레이터·알고리즘 개념을 정리한 뒤, vector 클래스와 `<algorithm>` 함수(sort, max_element 등)를 이용해 정렬·탐색·행렬 연산 등을 구현하는 실습으로 이어집니다. 10-5장의 2차원 배열 기반 행렬 문제를 10-6장에서 vector로 다시 구현해보며 두 방식을 비교합니다.

### 10-1장 - 템플릿 함수
배열에서 최댓값을 구하는 함수를 템플릿 함수(getmax)로 정의하는 문제와, Circle 객체에 대한 > 연산자 함수를 정의해 템플릿 코드가 정상 동작하도록 수정하는 문제로 구성됩니다.

📁 [10-1장/](./10-1장/)

### 10-2장 - 템플릿 클래스
템플릿 클래스 GClass를 정의하고 두 값을 교환하는 swap 멤버함수를 추가하는 문제, 그리고 크기를 매개변수로 받아 동작하는 템플릿 클래스를 작성하는 문제로 구성됩니다.

📁 [10-2장/](./10-2장/)

### 10-3장 - STL 개념과 vector
STL의 컨테이너·이터레이터·알고리즘 함수의 역할, 포인터와 iterator의 공통점·차이점, vector의 erase/insert 멤버함수의 매개변수·리턴값·기능을 서술형으로 정리하고(실습과제1), 정수 4개를 입력받아 최댓값·최솟값을 구하거나(실습과제2) 정수 5개 중 음수를 erase로 제거한 뒤 평균을 구하는(실습과제4) 등 vector 클래스와 멤버함수만으로 구현하는 실습으로 이어집니다.

📁 [10-3장/](./10-3장/)

### 10-4장 - STL vector와 알고리즘
STL의 vector 클래스와 `<algorithm>` 함수(sort, max_element 등)를 이용해 정수를 크기순으로 정렬하거나, 이름·점수를 저장하는 Student 클래스에 `<` 연산자를 정의해 max_element로 최고 점수 학생을 찾는 등의 실습으로 구성됩니다.

📁 [10-4장/](./10-4장/)

### 10-5장 - 2차원 배열과 연산자 오버로딩
2차원 배열로 표현한 행렬의 덧셈·최댓값과 위치 찾기·조건별 값 치환(음수→0, 양수→255)을 구현하고, 3명 학생의 세 과목 평균을 구해 최우수 학생을 찾는 문제로 구성됩니다. 연산자 오버로딩으로 행렬 연산을 더 간결하게 구현해볼 것을 권장하는 문제도 포함됩니다.

📁 [10-5장/](./10-5장/)

### 10-6장 - vector로 구현하는 행렬 연산
10-5장과 동일한 문제들(행렬 계산, 최댓값과 위치 찾기, 음수→0/양수→255 치환, 학생 평균으로 최우수 학생 찾기)을 이번에는 2차원 배열 대신 vector 클래스를 이용해 다시 구현하는 실습입니다.
