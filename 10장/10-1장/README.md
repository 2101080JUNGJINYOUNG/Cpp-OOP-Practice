# 10-1장 - 템플릿 함수

배열에서 최댓값을 구하는 함수를 템플릿 함수(getmax)로 정의하는 문제와, Circle 객체에 대한 > 연산자 함수를 정의해 템플릿 코드가 정상 동작하도록 수정하는 문제로 구성됩니다.

## 실습과제

<details>
<summary>실습과제1</summary>

크기 n인 배열에서 최댓값을 구해 리턴하는 함수 getmax를 템플릿 함수로 정의해, int·double 등 여러 자료형의 배열에 대해 하나의 함수 정의로 동작하도록 구현합니다.

📁 [해당 폴더로 이동](./실습과제1/)

</details>

<details>
<summary>실습과제2</summary>

Circle 객체들을 담은 배열에서 최댓값을 비교하려면 두 Circle을 비교하는 `>` 연산자가 필요하므로, Circle 클래스에 `>` 연산자 함수를 정의해 템플릿 함수(getmax 등)가 Circle에도 그대로 동작하도록 만드는 실습입니다.

📁 [해당 폴더로 이동](./실습과제2/)

</details>
