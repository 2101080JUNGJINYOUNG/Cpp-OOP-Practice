# Cpp-OOP-Practice

C++ 수업에서 진행한 프렌드/연산자 오버로딩(7장), 상속(8장), 템플릿·STL(10장) 실습 과제를 정리한 저장소입니다. 같은 기능을 전역함수·멤버함수·프렌드 함수로 번갈아 구현해보며 각 방식의 차이를 비교하고, 상속에서의 접근 지정자와 생성자 호출 순서, 템플릿과 STL을 이용한 정렬·탐색·행렬 연산까지 다룹니다.

## 배운 것 / 깨달은 것 / 성취한 것

7장에서 같은 덧셈 기능을 전역함수 → 멤버함수 → 프렌드 함수로 세 번 옮겨 구현해보면서, 연산자 함수를 어디에 두느냐에 따라 private 멤버 접근 권한이 어떻게 달라지는지, 그리고 멤버함수와 프렌드 함수가 문법적으로 어떻게 다른지를 코드로 직접 비교할 수 있었습니다. 교재 366~372페이지 문제에서 Book·Color 클래스의 같은 연산자(+=, ==, `<` 등)를 매번 멤버함수판과 프렌드 함수판으로 나눠 구현하면서, 두 방식이 결과는 같아도 클래스 정의 안에 놓이는지 밖에 놓이는지에 따라 코드 구조가 달라진다는 걸 체감했습니다. 8장에서는 Shape 클래스의 멤버를 private으로 뒀을 때와 protected로 뒀을 때 파생 클래스(Circle·Rect·Triangle)에서 접근 가능 여부가 달라지는 걸 직접 코드로 확인했고, TV→WideTV→SmartTV 3단계 상속 구조에서 SmartTV 객체를 생성하면 생성자가 최상위 부모부터 순서대로 호출된다는 것을 실습과제1에서 분석하면서 상속의 생성자 호출 순서를 이론이 아니라 실제 호출 흐름으로 이해할 수 있었습니다. 10장에서는 배열의 최댓값을 구하는 getmax 함수를 템플릿 함수로 만들어보면서 자료형이 달라도 하나의 함수 정의로 재사용할 수 있다는 점을 익혔고, STL의 컨테이너·이터레이터·알고리즘 개념을 정리한 뒤 vector와 `<algorithm>`(sort, max_element 등)을 이용해 정렬·탐색·행렬 연산을 구현하면서, 특히 10-5장의 2차원 배열 기반 행렬 문제를 10-6장에서 vector로 다시 구현해보니 같은 문제라도 자료구조를 무엇으로 선택하느냐에 따라 코드 작성 방식이 달라진다는 걸 알 수 있었습니다.
전체적으로 이 저장소를 정리하면서 가장 크게 느낀 건, C++의 연산자 오버로딩·상속·템플릿이 각각 독립된 문법이 아니라 "같은 기능을 여러 방식으로 구현해보고 비교하는" 과정을 통해서 왜 그런 문법이 필요한지 체감할 수 있었다는 점입니다.

## 실습 목록

### 07장 - 프렌드와 연산자 오버로딩
실수부·허수부를 멤버로 갖는 Complex 클래스를 예제 삼아, 같은 연산 기능을 전역함수 → 멤버함수 → 프렌드 함수로 옮겨가며 구현해보고, 이 과정에서 함수 중복·연산자 중복·연산자 함수·다형성 같은 개념을 정리합니다. 교재 366~372페이지 문제를 통해 Book·Color 클래스의 다양한 연산자(+=, -=, ==, !, `<`)를 멤버함수·프렌드 함수 두 방식으로 구현하며 두 방식의 차이를 직접 비교합니다.

### 08장 - 상속
위치좌표를 멤버로 갖는 Shape 클래스를 상속받는 Circle·Rect·Triangle 파생 클래스를 작성하며 private/protected 접근 지정자가 상속에 미치는 영향을 확인하고, TV→wideTV→SmartTV로 이어지는 다단계 상속에서 생성자 호출 순서를 분석합니다. Circle을 상속받는 NamedCircle 클래스를 작성해 배열로 여러 객체를 다루는 문제로 마무리됩니다.

📁 [08장/](./08장/)

### 10장 - 템플릿과 STL
템플릿 함수·템플릿 클래스로 자료형에 독립적인 코드를 작성하는 법을 배우고, STL의 컨테이너·이터레이터·알고리즘 개념을 정리한 뒤, vector 클래스와 `<algorithm>` 함수(sort, max_element 등)를 이용해 정렬·탐색·행렬 연산 등을 구현하는 실습으로 이어집니다. 10-5장의 2차원 배열 기반 행렬 문제를 10-6장에서 vector로 다시 구현해보며 두 방식을 비교합니다.
