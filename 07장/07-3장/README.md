# 07-3장 - 연산자 함수를 멤버함수로 구현

real·img를 멤버로 갖는 Complex 클래스에 연산자 함수를 멤버함수로 두 차례 구현하고, 추가로 Power 클래스를 정의하는 실습입니다.

## 실습과제

<details>
<summary>실습과제1</summary>

실수부(real)·허수부(img)를 멤버로 갖는 Complex 클래스에 + 연산자 함수를 클래스의 멤버함수로 직접 구현해, Complex 객체끼리 + 기호로 바로 더할 수 있도록 만드는 실습입니다.

📁 [해당 폴더로 이동](./실습과제1/)

</details>

<details>
<summary>실습과제2</summary>

Complex 클래스에 + 연산자 외에 추가 연산자(예: - 등)를 더 멤버함수 방식으로 구현해, 여러 연산자를 오버로딩하는 방법을 확장 연습하는 실습입니다.

📁 [해당 폴더로 이동](./실습과제2/)

</details>

<details>
<summary>실습과제3</summary>

거듭제곱 값을 표현하는 Power 클래스를 새로 정의하고, 필요한 연산자 함수를 멤버함수로 구현해 실행 결과와 같은 동작을 재현하는 실습입니다.

📁 [해당 폴더로 이동](./실습과제3/)

</details>
