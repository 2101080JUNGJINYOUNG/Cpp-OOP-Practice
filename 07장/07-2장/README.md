# 07-2장 - 함수 중복과 연산자 오버로딩 개념 정리

함수 중복(오버로딩)과 연산자 중복의 개념, 연산자 함수(operator 키워드로 정의하며 멤버함수 또는 전역함수로 구현 가능)의 의미, 객체지향의 다형성 개념을 서술형으로 정리한 문제입니다.

## 실습과제

<details>
<summary>문제1 - 함수 중복</summary>

같은 이름의 함수를 매개변수 개수·타입이 다르게 여러 개 정의할 수 있는 기능(오버로딩)이 무엇인지 설명하는 문제입니다.

</details>

<details>
<summary>문제2 - 연산자 중복</summary>

같은 연산자가 피연산자의 타입에 따라 서로 다른 동작을 하도록 만드는 연산자 오버로딩의 개념을 설명하는 문제입니다.

</details>

<details>
<summary>문제3 - 연산자 함수</summary>

operator 키워드로 정의하며, 클래스의 멤버 함수 또는 전역(프렌드) 함수 형태로 구현할 수 있는 연산자 함수의 정의를 설명하는 문제입니다.

</details>

<details>
<summary>문제4 - 다형성</summary>

동일한 인터페이스로 서로 다른 타입의 객체를 처리할 수 있는 객체지향의 다형성 개념을 설명하는 문제입니다.

</details>
