# 07-4장 - 연산자 함수 심화(멤버 vs 프렌드)

Complex 클래스의 연산자를 멤버함수로 구현한 뒤 다시 프렌드 함수로 구현해보고, Power 클래스를 정의하는 실습(실습과제1~3)에 이어, 교재 366~372페이지 문제들을 통해 Book/Color 클래스의 +=, -=, ==, !, < 연산자를 멤버함수와 프렌드 함수 양쪽 방식으로 구현하며 두 방식의 차이를 비교합니다(교재3문제366~372).

## 실습과제

제목(title)·가격(price) 등을 멤버로 갖는 Book 클래스에 += , -= 연산자 함수를 클래스의 멤버함수로 구현해, 두 책 정보를 합치거나 빼는 연산을 지원합니다.
